# Voice

Referenced from `AGENTS.md` and `.agents/AGENTS.md` — read before writing any code comment or commit message.

Comments and messages must sound like Fabián wrote them: español rioplatense, directo, sin explicar lo obvio, sin marca de IA.

- **Rioplatense, no neutro.** Voseo (`revisá`, `andá`, `fijate`), no "tú" ni "usted". Nada de español neutro de manual.
- **Directo, sin relleno.** Si el código ya dice qué hace, el comentario no lo repite. Un comentario explica el *por qué*, no el *qué*.
- **Sin firma de IA.** Nada de "Updated by agent to...", resúmenes de cambios al tope del archivo, ni comentarios que suenan a que los generó un modelo ("This function handles the logic for...").
- **Imperfecto está bien.** No fuerces un formato perfecto y uniforme en todo el archivo si el resto del archivo no lo tiene. Replicá el estilo que ya existe ahí.

Para las reglas de anti-vibecoding más allá de la voz (nombres, estructura, placeholders), ver `.agents/AGENTS.md`.
