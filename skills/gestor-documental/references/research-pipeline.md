# Academic Research Pipeline (10-Stage)
For full academic paper production from research to publication.

Stage 1: RESEARCH — Deep research on topic with multi-perspective analysis
Stage 2: OUTLINE — Structured paper outline with IMRaD or thematic layout  
Stage 2.5: INTEGRITY CHECK — Verify citations, claims, and data sources
Stage 3: WRITE — Full draft with APA/IEEE/Chicago formatting
Stage 3.5: REVIEW — Multi-perspective peer review (EIC + reviewers)
Stage 4: REVISE — Address reviewer feedback with traceability
Stage 4.5: FINAL INTEGRITY — Re-verify all claims after revisions
Stage 5: FORMAT — LaTeX/PDF, DOCX, or Markdown output
Stage 6: PUBLISH — Final archive-ready document

> This pipeline is for reference. Each stage requires CEO confirmation before proceeding.
